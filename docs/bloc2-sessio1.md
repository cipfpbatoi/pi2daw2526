# Sessió 1. Investigar necessitats

## Objectiu

Explorareu diferents contextos, formulareu problemes sense anticipar la solució i decidireu quines necessitats mereixen una investigació breu.

## Organització

| Activitat | Temps | Treball |
| --- | ---: | --- |
| 1. Acord inicial de l'equip | 20 min | Equip |
| 2. Banc de situacions | 35 min | Individual i equip |
| 3. Primera selecció | 25 min | Equip |
| 4. Investigació breu | 75 min | Equip, amb responsabilitats identificades |
| 5. Síntesi i pròxim pas | 25 min | Equip i individual |

## Activitat 1. Acord inicial

Registreu els membres, les vies de comunicació i un repartiment inicial per a esta sessió. Assigneu una persona responsable de cada tasca, però eviteu convertir els rols en especialitats permanents.

## Activitat 2. Banc de situacions

Cada membre proposarà almenys dues situacions problemàtiques procedents de dominis diferents. Podeu partir d'un col·lectiu, una organització, un procés o una oportunitat observable.

| Situació actual | Qui resulta afectat? | Indici o evidència | Què falta saber? | Possible aportació web, sense concretar-la encara |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

Reviseu cada formulació:

- descriu un efecte o una necessitat, i no «falta una app»?;
- hi ha alguna persona o organització a qui puguem consultar?;
- podem trobar informació fiable durant el bloc?;
- té relació amb les competències de DAW?;
- permet imaginar més d'una resposta possible?

## Activitat 3. Primera selecció

Agrupeu propostes semblants i seleccioneu-ne **entre dues i quatre** per investigar. No voteu només segons preferències personals: utilitzeu estos filtres.

| Necessitat candidata | Rellevància | Accés a informació o persones | Possibilitat de validació | Adequació a DAW | Dubte principal |
| --- | --- | --- | --- | --- | --- |
|  | Baixa/mitjana/alta |  |  |  |  |

Descartar una candidata exigix una raó breu. Conserveu el registre per poder recuperar-la si una opció posterior resulta inviable.

## Activitat 4. Investigació breu

Per cada candidata seleccionada, definiu primer què necessiteu saber i quin mètode vos pot donar eixa informació.

| Pregunta d'investigació | Font o mètode | Responsable | Resultat | Fiabilitat o limitació | Decisió afectada |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

Heu d'incloure, com a mínim:

- una font externa amb autoria identificable;
- una evidència pròxima al context —persona interessada, observació, dades o procés documentat—, si és accessible;
- un contrast que evite basar la necessitat en una única opinió;
- una limitació de la investigació.

!!! warning "Contacte amb persones externes"

    No envieu formularis massius ni contacteu una organització en nom del centre sense acordar-ho abans amb el professorat. No incorporeu dades personals innecessàries al dossier.

## Activitat 5. Síntesi

Redacteu una fitxa breu per cada candidata:

1. context i situació actual;
2. persones afectades i necessitats diferents;
3. causes i conseqüències confirmades o hipotètiques;
4. evidències disponibles;
5. informació que encara falta;
6. per què podria justificar un projecte DAW.

Cada membre afegirà una nota individual: quina candidata considera més prometedora, quina evidència sosté la seua opinió i què podria fer-li canviar d'idea.
