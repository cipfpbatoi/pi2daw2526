# Bloc 4. Planificació de l'execució

## Convertir un avantprojecte alié en un pla executable

En este bloc assumireu la custòdia del projecte dissenyat per una altra parella. La vostra responsabilitat no és refer-lo segons els vostres gustos, sinó entendre'l, detectar buits i convertir-lo en un **pla que una tercera parella puga executar**.

Disposareu de **12 hores, en quatre sessions**. Treballareu sobre la versió del Dossier 2 identificada en l'acta de traspàs. Les consultes a l'equip autor, els canvis d'abast i les decisions noves quedaran registrats en GitHub.

## Resultat del bloc

Preparareu el [Pla del projecte](bloc4-pla-projecte.md), amb:

- auditoria d'entrada i línia base acceptada;
- lliurables, descomposició del treball i tasques executables;
- dependències, prioritats, estimacions, recursos i responsabilitats;
- cronograma, fites, iteracions i valoració econòmica;
- permisos, riscos i procediments d'execució;
- tauler d'issues, criteris de finalització i política de versions;
- plans de proves, qualitat i desplegament;
- procediments per a incidències, canvis, seguiment i participació de persones usuàries;
- matriu de traçabilitat, evidències individuals i acta de traspàs.

## Regles del relleu

- L'equip autor conserva l'autoria; la parella planificadora assumix la custòdia.
- Una ambigüitat no es resol per conversa informal: s'obri una issue o es registra en l'acta.
- Un canvi de línia base necessita motiu, impacte i decisió visible.
- Les issues concretes les crea la parella planificadora a partir de les plantilles del repositori.
- Cada membre ha de poder explicar el pla global i acreditar aportacions pròpies.

## Punt de control

El pla serà **apte per executar**, **apte amb ajustos** o **retornat a planificació**. Superar el punt de control no significa que totes les estimacions siguen exactes: significa que són justificades, que les dependències i els riscos són visibles i que una altra parella pot començar sense reconstruir el projecte.

La versió acceptada es marcarà com `pla-v1.0` i es traspassarà a la parella prototipadora. GitHub conservarà el treball i les evidències; en Aules s'entregarà l'enllaç immutable indicat pel professorat.
