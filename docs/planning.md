# Planificació setmanal del Projecte Integrador (2n DAW)

La duració del mòdul és de 99 hores, amb una sessió setmanal de 3h per grup.  
Els **grups A i B** realitzen el mateix contingut, però en dies diferents:
- **Grup A** → dimarts
- **Grup B** → divendres
